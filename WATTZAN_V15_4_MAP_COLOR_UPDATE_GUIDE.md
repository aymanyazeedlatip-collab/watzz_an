# WATTZAN v15.4 — Softer Indigo Map Gradient

## Change

The highest-consumption end of the Overview 3D map was changed from strong purple to a restrained blue-violet indigo.

New scale:

White → Light Blue → Blue → Royal Blue → Indigo

Final high-value color: `#4F46E5`

This keeps the map predominantly blue while still visually distinguishing the highest value.

## Installation

1. Stop WATTZAN with `Ctrl + C`.
2. Extract `WATTZAN_v15_4_Softer_Indigo_Gradient_Update.zip`.
3. Copy the extracted `frontend` folder into the current WATTZAN project.
4. Choose **Replace the files in the destination**.
5. Restart `backend/run_server.bat`.
6. Open the dashboard and press `Ctrl + F5`.

## Scope

Only these frontend files changed:

- `frontend/app.js`
- `frontend/styles.css`

Forecasting, weather retrieval, chatbot, database, trained model artifacts, and backend code are unchanged.
