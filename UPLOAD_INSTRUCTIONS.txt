WATTZAN TOUCH + CHAT RELIABILITY FIX V3
======================================

UPLOAD THESE EXACT PATHS:

1. public/runtime-fixes.js             NEW
2. public/dependency-loader.js         REPLACE
3. frontend/runtime-fixes.js           NEW
4. frontend/dependency-loader.js       REPLACE

WHAT THIS FIXES
- Mobile 3D overview map: a real short touch tap now bridges to the map's existing
  click/raycast selection, so municipality details open reliably. Dragging/rotating
  the 3D map is not converted into a click.
- Chatbot reliability: transient 408/425/429/500/502/503/504 and network failures
  are retried automatically instead of forcing the user to resend the question.
- Backend warmup: /api/health is called silently after page load and when the
  assistant is opened, reducing free-backend cold-start failures.

NOT CHANGED
- app.js forecasting/model/map logic
- styles.css or mobile.css
- backend Python/API/model files
- desktop layout
- forecast calculations or stored data

The new runtime file is optional/fail-safe: if it cannot load, WATTZAN still starts
with the existing application exactly as before.
