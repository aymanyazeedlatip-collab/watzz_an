WATTZAN v16.1 UPDATE INSTALLATION

1. Extract this ZIP.
2. Copy all extracted files/folders into the ROOT of your existing WATTZAN
   GitHub repository.
3. Choose Replace files in the destination when Windows asks.
4. In GitHub Desktop, commit with: Fix 3D map dependency loading and runtime reliability
5. Push origin.
6. Wait for the Vercel Production deployment to become Ready.
7. Open the website and press Ctrl+F5 once.
8. Open Overview and confirm the 3D map renders.
9. Check /api/health and /api/deployment-diagnostics.

No Vercel environment variable changes are required.
